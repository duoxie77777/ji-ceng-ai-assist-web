# ji-ceng-ai-assist-web

基于 Vue 3 + TypeScript + Vite 的前端项目

## 技术栈

- Vue 3 + TypeScript
- Vite（使用 Rolldown）
- Vue Router + Pinia
- iconfont 图标库

## 快速开始

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview

# 更新 iconfont 图标
npm run update-icon
```

## 图标使用

```vue
<SvgIcon name="Vue" />
<SvgIcon name="Vue" :size="32" color="#42b883" />
```
